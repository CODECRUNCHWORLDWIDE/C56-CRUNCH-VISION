# Week 6 — Resources

Curated, free where possible. You do not need all of these — pick what fits how you learn.

- [PyTorch — TorchVision Object Detection Finetuning tutorial](https://pytorch.org/tutorials/intermediate/torchvision_tutorial.html) — Faster R-CNN end to end.
- Ren et al. (2015) — *Faster R-CNN*; Redmon et al. — *YOLO*; Lin et al. — *Focal Loss / RetinaNet*: the foundational papers.
- Jonathan Hui — *mAP (mean Average Precision) for Object Detection*: the clearest metric walkthrough.
- torchmetrics — Mean Average Precision: a correct, tested mAP implementation to check against.
- COCO dataset & evaluation docs — the standard detection benchmark and metric definitions.

> All external links are references, not endorsements. Prefer primary sources (papers, official docs) when they exist.
