# Week 12 — Homework

The capstone *is* the week. This 'homework' is the finishing polish.

## Tasks

- Write the limitations and dataset-bias section of your capstone before you think you're done — it will change what you fix.
- Have someone else (or a fresh terminal) clone your repo and follow the README; fix whatever they can't reproduce, and confirm the served API returns the right answer on a real image.
- Complete the model card, including per-subgroup metrics, named failure modes, and privacy/consent/bias considerations.
- Write your two-paragraph project defense (Challenge 2) — anticipate and answer the toughest technical and ethical critique.

## Definition of done

A committed, reproducible repository with problem framing (task + metric + baseline), a trained vision model beating (or honestly analyzed against) the baseline on held-out images, honest evaluation (task-appropriate metric, visual error analysis, per-subgroup/bias check, named failure modes), a served inference API with verified preprocessing parity, a model card addressing privacy/consent/bias, and a reproduce-me README.

Submit by committing your work to your course repo under `week-12/`.
