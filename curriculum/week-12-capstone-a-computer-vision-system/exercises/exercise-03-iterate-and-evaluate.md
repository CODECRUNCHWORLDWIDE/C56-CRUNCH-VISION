# Exercise 3 — Iterate, then evaluate honestly

**Goal:** improve the model and evaluate like a professional.

## Tasks

1. Improve the model deliberately — transfer learning, the Week-4 training toolbox, augmentation, the right architecture for the task — logging what each change bought.
2. When done improving, run the **full honest evaluation**: held-out metric vs. baseline, a confusion matrix / PR curves / per-class scores as fits the task, a *visual* error analysis on the mistakes, and per-subgroup / bias performance where relevant.
3. Write the limitations and failure modes you found, including any dataset bias.

## Deliverable

An evaluation report with the results-vs-baseline table, a visual error gallery, a bias/subgroup check, and a named-limitations section. This report is the heart of the capstone.
