# Week 2 — Resources

Curated, free where possible. You do not need all of these — pick what fits how you learn.

- [OpenCV — Feature Detection and Description tutorials](https://docs.opencv.org/4.x/db/d27/tutorial_py_table_of_contents_feature2d.html) — Harris, SIFT, ORB, matching, and homography, with runnable code.
- Canny (1986), *A Computational Approach to Edge Detection*, *IEEE TPAMI* — the original paper; read §II for the optimality criteria.
- Lowe (2004), *Distinctive Image Features from Scale-Invariant Keypoints*, *IJCV* — SIFT, the ratio test, and scale invariance, in full.
- Hartley & Zisserman, *Multiple View Geometry in Computer Vision* (2004), Ch. 4 — the normalized DLT and homography estimation; the geometry reference.
- Szeliski, *Computer Vision: Algorithms and Applications* (2nd ed., 2022) — free PDF; Ch. 7 (features) and Ch. 8 (alignment/stitching) cover this whole week.
- First Principles of Computer Vision (YouTube, Shree Nayar, Columbia) — clear, rigorous lectures on edges, corners, SIFT, and image alignment.
- Mikolajczyk & Schmid (2005), *A Performance Evaluation of Local Descriptors*, *IEEE TPAMI* — how repeatability and matching are actually measured.
- kornia and OpenCV `xfeatures2d` / `SuperPoint`/`LoFTR` demos — hands-on comparison of classical vs. learned local features on the same pairs.

> All external links are references, not endorsements. Prefer primary sources (papers, official docs) when they exist.
