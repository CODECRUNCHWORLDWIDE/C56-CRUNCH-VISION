# Week 2 — Resources

Curated, free where possible. You do not need all of these — pick what fits how you learn.

- [OpenCV — Feature Detection and Description tutorials](https://docs.opencv.org/4.x/db/d27/tutorial_py_table_of_contents_feature2d.html) — Harris, SIFT, ORB, matching.
- Canny (1986) — *A Computational Approach to Edge Detection*: the original, surprisingly readable.
- Lowe (2004) — *Distinctive Image Features from Scale-Invariant Keypoints* (SIFT): the ratio test and scale invariance.
- Szeliski — *Computer Vision*, Ch. 4 (feature detection) and Ch. 8 (image alignment/stitching).
- First Principles of Computer Vision (YouTube, Shree Nayar) — clear lectures on edges, corners, and features.

> All external links are references, not endorsements. Prefer primary sources (papers, official docs) when they exist.
