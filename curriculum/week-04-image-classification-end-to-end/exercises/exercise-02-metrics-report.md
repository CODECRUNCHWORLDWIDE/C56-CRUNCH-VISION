# Exercise 2 — A full metrics report

**Goal:** evaluate like a professional, not with a single number.

## Tasks

1. Train (or reuse) a classifier on your dataset. On the validation set, compute overall accuracy, per-class precision and recall, and a confusion matrix.
2. Compute macro-averaged and micro-averaged F1 and explain when they differ (hint: class imbalance).
3. If your dataset has many classes, add top-3 accuracy.
4. From the confusion matrix, name the two most-confused class pairs and hypothesize *why* (visual similarity, few examples, label noise).

## Deliverable

A notebook producing a metrics table + confusion matrix and a short written error analysis naming the confused pairs and a hypothesis for each. The analysis matters more than the accuracy number.
